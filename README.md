# JAVA — תרגילי Java

מאגר תרגול המכיל דוגמאות ותרגילים שונים ב־Java. כל קובץ תרגול פועל באופן עצמאי; אין כאן אפליקציה מאוחדת או מערכת בנייה משותפת. מימושים חדשים ממוקמים בענפי פיתוח כדי לא להתנגש בתרגילים וב־PRs קיימים.

## אנגרמות (Java 17 ומעלה)

הקובץ `anagram.java` תומך בבדיקה אינטראקטיבית של שתי מחרוזות, בבדיקה ישירה משורת הפקודה ובזיהוי קבוצות של אנגרמות מתוך קובץ UTF-8. הוא משתמש בספרייה הסטנדרטית בלבד ואינו פונה לרשת או משנה את קובץ הקלט.

```bash
javac -encoding UTF-8 anagram.java
java anagram
java anagram --compare "Rail safety" "Fairy tales"
java anagram --groups words.txt
```

במצב `--groups`, כל שורה בקובץ היא מילה או צירוף מילים אחד. לדוגמה, קובץ:

```text
listen
silent
enlist
Apple
Papel
stone
```

מחזיר שתי קבוצות: `listen | silent | enlist` וגם `Apple | Papel`. קבוצות מסודרות לפי גודלן מהגדולה לקטנה, ואז לפי המפתח המנורמל. קבוצות שבהן אין לפחות שתי מחרוזות שונות אינן מוצגות. כפילויות זהות בתוך אותה קבוצה אינן נספרות שוב.

השוואה מנרמלת ל־Unicode NFKC, ממירה לאותיות קטנות באמצעות `Locale.ROOT`, מתעלמת מרווחים ומסימני פיסוק ושומרת אותיות, ספרות וסימני ניקוד משולבים. משמעות הדבר היא ש־`Rail safety` ו־`Fairy tales` הן אנגרמות, ושסימני ניקוד עשויים להשפיע על ההתאמה; אין כאן ניתוח מילוני או לשוני. טקסט המורכב מפיסוק או רווחים בלבד **אינו** נחשב לאנגרמה של טקסט ריק אחר.

מגבלות לקלט קובץ: קובץ רגיל שאינו symlink, לכל היותר 8 MiB ו־50,000 שורות, ולכל ערך לכל היותר 512 תווי Unicode. שגיאות שימוש בארגומנטים מחזירות קוד 2; שגיאות קלט וקובץ מחזירות קוד 1. במצב השוואה, הפלט מציין אם המחרוזות הן אנגרמות אך קוד היציאה אינו מבדיל בין תשובת כן ולא. מחרוזות ארוכות מאוד נדחות כדי להגביל שימוש בזיכרון.

הכלי אינו משנה את התרגילים האחרים ב־Java, לרבות ה־PR הפתוח של משחק Hangman. הוא הועלה לענף פיתוח אך לא הורץ, קומפל או נבדק בסבב הזה. הבדיקות והמיזוג יבוצעו רק במסגרת סבב הקבלה המרוכז.
